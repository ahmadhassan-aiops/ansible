# 21. Installing Packages from a List Variable

This topic uses a list to store the names of the packages to install.

## CentOS

```yaml
# sudo vim packages.yml
---
- name: this yml file is dedicated to installation of packages
  hosts: centos
  become: yes
  vars:
    packages: ["wget","zip","curl"]
  tasks:
  - name: installation of packages using yum
    yum:
      name: "{{ packages }}"
      state: present
```

## Ubuntu

```yaml
# vim list_pack_install.yml
---
- name: this yml file is dedicated to installation of packages
  hosts: ubuntu
  become: yes
  vars:
    packages: ["wget", "zip", "curl"]
  tasks:
  - name: installation of packages using apt
    apt:
      name: "{{ packages }}"
      state: present
      update_cache: yes
```
