# 10. Copy and Fetch Modules in Playbooks

## Copying Files

```yaml
# sudo vim copy.yml
---
- name: this yml file focuses on copying files
  hosts: ubuntu
  become: yes
  tasks:
    - name: Copying ansible.cfg file
      copy:
        src: /home/john/ansible/ansible.cfg
        dest: /home/ubuntu/
```

Check your file for errors:

```bash
ansible-playbook copy.yml --check

# another way
ansible-playbook copy.yml --syntax-check
```

**Key=value style:**

```yaml
---
- name: this yml file focuses on copying files
  hosts: ubuntu
  become: yes
  tasks:
    - name: Copying ansible.cfg file
      copy: src=/home/john/ansible/ansible.cfg dest=/home/sara/
```

## Fetching Files from the Worker Machine

**Key=value style:**

```yaml
---
- name: this yml file focuses on copying files
  hosts: ubuntu
  tasks:
    - name: Copying ansible.cfg file
      fetch: src=/home/ubuntu/ansible.cfg dest=/home/john/ansible/
```

To copy the file directly into your destination folder (without the extra directories), add `flat=yes`:

```yaml
---
- name: this yml file focuses on copying files
  hosts: ubuntu
  tasks:
    - name: Copying ansible.cfg file
      fetch: src=/home/ubuntu/ansible.cfg dest=/home/john/ansible/ flat=yes
```
