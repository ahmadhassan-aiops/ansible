# 31. Connecting a Windows Machine with Ansible

## Step 1: Create a User on the Windows Machine

1. Open **Run** and type `lusrmgr.msc`. This opens user management, where you can create a new user.
2. Make the new user a member of the **Administrators** group: right-click the user → **Properties** → **Member Of** → **Add** → **Advanced** → **Find Now** → choose **Administrators**.
3. Remove every group other than Administrators.

> Sending a file to a Windows machine over WinRM is covered in [Task 9 of the practical tasks](32.%20Ansible%20Practical%20Tasks%20with%20Solutions.md#task-9-send-a-file-to-a-windows-machine).
