# 25. Operators and Filters

**Types of operators:**

1. Arithmetic operators
2. Comparison operators
3. Logical operators
4. Bitwise operators, e.g. `&` `|` `^`
5. Identity: `a is b`, `a is not b`
6. Membership: `a in b`, `a not in b`

## Arithmetic Operators

- In this playbook, the variables are defined inside the playbook.
- Variables taken as input from the command line are interpreted as **strings**. Convert them to integers inside the playbook, or the operation gives errors.
- Example: `"Sum of two numbers: {{ (a | int) + (b | int) }}"` converts both input variables to integers before adding them.

```yaml
# vim arithmetic.yml
---
- name: this yml file is for arithmetic operators
  hosts: localhost
  become: yes
  vars:
    a: 5
    b: 15
  tasks:
  - name: performing arithmetic operation
    debug:
      msg:
      - "Sum of two numbers is {{ a + b }} "
      - "Difference of two numbers is {{ a - b }} "
      - "Multiplication of two numbers is {{ a * b }}"
      - "Division of two numbers is {{ a / b }}"
```

## Comparison Operators

```yaml
# sudo vim comparison.yml
---
- name: this yml file is for comparison operators
  hosts: localhost
  vars:
  - a: 15
  - b: 25
  - mylist: [10,20,3,0,12,40]
  - myname: "ahmad"
  tasks:
  - name: performing comparison operators
    debug:
      msg:
      - " a and b are equal: {{ a == b }}"
      - " a and b are not equal: {{ a != b }}"
      - " a is greater than b: {{ a > b }}"
      - " a is less than b: {{ a < b }}"
      - " checking two conditions if a is greater or b: {{ a > 5 or b > 10 }}"
      - " Maximum number in my list: {{ mylist | max }} "
      - "Checking if myname is present: {{ myname in 'ahmad' }} "
```

```console
[john@master-ansible ansible]$ ansible-playbook comparison.yml

PLAY [this yml file is for comparison operators] *****************************************************************************

TASK [Gathering Facts] *******************************************************************************************************
ok: [localhost]

TASK [performing comparison operators] ***************************************************************************************
ok: [localhost] => {
    "msg": [
        " a and b are equal: False",
        " a and b are not equal: True",
        " a is greater than b: False",
        " a is less than b: True",
        " checking two conditions if a is greater or b: True",
        " Maximum number in my list: 40 ",
        "Checking if myname is present: True "

}
```

## Combining Input, Arithmetic, Comparison and Filters

```yaml
# vim operators.yml
---
- hosts: localhost
  vars_prompt:
  - name: c
    prompt: "enter the C value:"
    private:  no
  - name: d
    prompt: "Enter the D value:"
    private: no
  vars:
    a: 10
    b: 5
    name1: "Ahmad"
    name2: "Hassan"
    lists: [1,4,8,4,2,16]
    my_lists:
    - one
    - two
    - three
  tasks:
  - name: Arithmetic operators
    debug:
      msg:
       - "{{ a + b }}"
       - "my {{c}} and {{d}} total is : {{c|int+d|int}}"
       - "{{ a - b }}"
       - "{{ a * b }}"
       - "{{ a / b }}"
       - "{{ a % b }}"
       - "{{ a ** b }}"
  - name: Comparison operators
    debug:
      msg:
       - "{{ a == b }}"
       - "{{ a != b }}"
       - "{{ a < b }}"
       - "{{ a > b }}"
       - "{{ a <= b }}"
       - "{{ a >= b }}"
       - "{{ name1 in 'Ahmad'}}"
       - "{{ a > 5 or b > 10 }}"
       - "{{lists|max}}"
       - "{{lists|min}}"
       - "{{name1|lower}}"
       - "{{name1|upper}}"
       - "{{name1|title}}"
       - "{{name1|replace('a','A') }}"
       - "{{ my_lists | join(', ') }}"
```
