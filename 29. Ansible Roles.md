# 29. Ansible Roles

## What Are Ansible Roles? (Interview Question)

- Ansible roles are a way to organize playbooks.
- They arrange tasks in a structured way.
- They make it easier to manage and reuse Ansible code.
- A role is essentially a collection of tasks, templates, files and variables.

## How a Role Is Organized

- There is a `roles` directory, and a project directory inside it.
- The project directory contains several directories (`tasks`, `vars`, `meta` and others), each with a `main.yml` file.
- Tasks are defined in `tasks/main.yml` and variables in `vars/main.yml`.
- A playbook outside the `roles` directory defines the hosts and other settings, and names the project under `roles`.

This way, everything runs in an organized way.

## Creating a Role

```bash
ansible-galaxy init <project name> --offline
```

```bash
# first make a roles directory
mkdir roles

# move inside it
cd roles

# create the project
ansible-galaxy init project --offline
```

```console
[john@master-ansible roles]$ tree
.
└── project
    ├── defaults
    │   └── main.yml
    ├── files
    ├── handlers
    │   └── main.yml
    ├── meta
    │   └── main.yml
    ├── README.md
    ├── tasks
    │   └── main.yml
    ├── templates
    ├── tests
    │   ├── inventory
    │   └── test.yml
    └── vars
        └── main.yml
```

## Calling the Role from a Playbook

The playbook outside the `roles` directory:

```yaml
- name: This is role example
  hosts: ubuntu
  become: yes
  gather_facts: false
  roles:
  - project
```
