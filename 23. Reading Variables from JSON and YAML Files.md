# 23. Reading Variables from JSON and YAML Files

> **Note:** quotes `""` are mostly needed when calling a variable. You can skip them when defining variables or reading a file, but they are a must when you call a variable.

## Reading a JSON File in a Playbook

First, define a JSON file (`sudo vim package.json`) that contains the package name and state:

```json
{
	"package_info":
	{
		"package_name": "zip",
		"package_state": "present"
	}
}
```

The package name and state are defined inside a key called `package_info`.

Now create a playbook to read the JSON file:

```yaml
# sudo vim read_json.yml
---
- name: this yml file read json file and use variables defined in it
  hosts: ubuntu
  become: yes

  vars:
    file_data: "package.json"   # declare the variable outside the tasks

  tasks:
    - name: reading file
      include_vars:
        file: "{{ file_data }}"

    - name: now installing the packages as our file has been read
      apt:                       # since the node is Ubuntu
        name: "{{ package_info.package_name }}"
        state: "{{ package_info.package_state }}"
      when: ansible_os_family == "Debian"

    - name: now installing the packages as our file has been read (for CentOS/RedHat)
      yum:
        name: "{{ package_info.package_name }}"
        state: "{{ package_info.package_state }}"
      when: ansible_os_family == "RedHat"
```

```console
[john@master-ansible ansible]$ ansible-playbook read_json.yml

TASK [Gathering Facts] *******************************************************************************************************
ok: [54.166.4.83]

TASK [reading file] **********************************************************************************************************
ok: [54.166.4.83]

TASK [now installing the packages as our file has been read] *****************************************************************
ok: [54.166.4.83]

TASK [now installing the packages as our file has been read (for CentOS/RedHat)] *********************************************

```

Once the file is read, its variables are available, which is why we can call the package name and state.

## Reading the File Directly

```yaml
# direct_read_json.yml
---
- name: this yml file read json file and use variables defined in it
  hosts: ubuntu
  become: yes
```

## Reading Packages from a YAML File

Instead of a JSON file, you can read the packages from a YAML file. Keep the dictionary format in both the JSON and YAML files.

```yaml
# vim package.yml
---
packages:
  package_wget:
    name: wget
    state: absent
  package_vim:
    name: vim
    state: present
```

Now create the playbook:

```yaml
# yml_reading_file.yml
---
- name: Reading yml file from playbook
  hosts: rhel
  gather_facts: false
  become: yes
  tasks:
  - name: Reading the yml file
    include_vars:
      file: package.yml

  - name: Installation wget
    yum:
      name: "{{ packages.package_wget.name }}"
      state: "{{ packages.package_wget.state }}"
```

```console
[john@master-ansible ansible]$ ansible-playbook yml_reading_file.yml

TASK [Reading the yml file] **************************************************************************************************
ok: [54.166.4.83]

TASK [Installation wget] *****************************************************************************************************

PLAY RECAP *******************************************************************************************************************
54.166.4.83                : ok=2    changed=1    unreachable=0    failed=0    skipped=0    rescued=0    ignored=0
```
