# 26. Loops in Playbooks

## Looping over a List

```yaml
# vim loop.yml
---
- name: Printing the words
  hosts: localhost
  vars:
    data:
      - Ahmad
      - Kazim
      - Ali
      - Sarah
  tasks:
  - name: Display the data
    debug:
      var: item
    loop: "{{data}}"
```

## Installing Packages in a Loop

```yaml
# vim loop_package.yml
---
- name: Installation package
  hosts: ubuntu
  become: yes
  vars:
    packages:
      - name: wget
        state: present
      - name: git
        state: present
  tasks:
  - name: Install package
    apt:
      name: "{{item.name}}"
      state: "{{item.state}}"
    loop: "{{packages}}"
```

On the first run the playbook still targeted `rhel`, so no hosts matched. After changing `hosts` to `ubuntu`, it ran:

```console
[john@master-ansible ansible]$ ansible-playbook loop_package.yml
```

## Creating Multiple Users (Interview Question)

**How do you create multiple users with an Ansible playbook?**

```yaml
# vim multiple_users.yml
---
- hosts: ubuntu
  become: yes
  vars:
    my_bulk_users:
      - username: ahmad
        password: Admin@123
      - username: kazim
        password: Admin@123
      - username: ali
        password: Admin@123
  tasks:
  - name: Bulk user creation
    user:
      name: "{{item.username}}"
      password: "{{item.password | password_hash('sha512') }}"
      update_password: on_create
    loop: "{{my_bulk_users}}"
```

**Removing the users:**

```yaml
# vim remove_users
---
- hosts: ubuntu
  become: yes

  vars:
    my_bulk_users:
      - { username: ahmad }
      - { username: kazim }
      - { username: ali }

  tasks:
    - name: Bulk user removal
      user:
        name: "{{ item.username }}"
        state: absent      # ensures the user is removed
        remove: yes        # also removes the home directory
      loop: "{{ my_bulk_users }}"
```

## Creating Multiple Files with Content

```yaml
# vim multiple_files.yml
---
- name: Files creation
  hosts: ubuntu
  become: true
  vars:
    my_files:
      - name: /tmp/ahmad1.txt
        content: "This is my ahmad1 file"
      - name: /tmp/ahmad2.txt
        content: We have ahmad2 data
  tasks:
  - name: Creation files
    copy:
      dest: "{{item.name}}"
      content: "{{item.content}}"
    loop: "{{my_files}}"
```

Only `dest` is needed in the copy task: we are creating new files, not copying existing ones, so no source is required.
