# 15. Collecting Remote Output with Playbooks

This topic is the opposite of the previous one. There, we defined Linux commands in a JSON file, read the file in Python and ran the commands. Now we run the commands directly in the Ansible playbook.

## Running Commands and Displaying Their Output

```yaml
# vim collect_cmd_details.yml
---
- hosts: all
  tasks:
  - name: Collecting hostname
    shell: "hostname | tr -d '\n'"   # run the command in the playbook, store its output, then show it with debug
    register: hostname_details
  - debug:
      var: hostname_details.stdout
  - name: Collecting IP address
    shell: "hostname -I | awk '{print $1}' | tr -d '\n'"
    register: ip_details
  - debug:
      var: ip_details.stdout
  - name: Collecting the disk storage output
    shell: "df -h | grep -v 'tmpfs'"
    register: df_details
  - debug:
      var: df_details.stdout_lines
```

## Saving the Output to a CSV File

```yaml
# vim collect_cmd_details_csv.yml
---
- hosts: all
  tasks:
  - name: Adding the header to CSV file
    lineinfile:
      path: /home/ubuntu/OS_OUTPUT.csv
      line: "HOSTNAME,IP ADDRESS,DF -h (mount details)"
      create: yes

  - name: Collecting hostname
    shell: "hostname | tr -d '\n'"
    register: hostname_details

  - debug:
      var: hostname_details.stdout

  - name: Collecting IP address
    shell: "hostname -I | awk '{print $1}' | tr -d '\n'"
    register: ip_details

  - debug:
      var: ip_details.stdout

  - name: Collecting the disk storage output
    shell: "df -h | grep -v 'tmpfs'"
    register: df_details

  - debug:
      var: df_details.stdout_lines

  - name: Save data to CSV file
    lineinfile:
      path: /home/ubuntu/OS_OUTPUT.csv
      line: "{{ hostname_details.stdout }},{{ ip_details.stdout }},\"{{ df_details.stdout }}\""
      create: yes

  - name: Fetch the CSV file to master machine
    fetch:
      src: /home/ubuntu/OS_OUTPUT.csv
      dest: /home/john/ansible/OS_OUTPUT_{{ inventory_hostname }}_{{ansible_date_time.hour}}{{ansible_date_time.minute}}.csv
      flat: yes
      backup: yes
```
