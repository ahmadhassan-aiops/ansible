# 09. Printing Messages with Playbooks

## Printing Messages

```yaml
# vim print.yml
---
- name: This file is dedicated for printing message
  hosts: ubuntu
  tasks:
    - name: Print multiple messages
      debug:
        msg:
          - "Sara Ali"
          - "Ahmad Hassan"
          - "Infinix"
```

## Choosing an Inventory File

If you have multiple inventory files (e.g. `hosts`, `inv`, `inv2`), mention which one to use when running the playbook:

```bash
ansible-playbook -i inv print.yml
```

Now the `inv` file is used to look up the hosts mentioned in `print.yml`.

## Using Variables in Messages

```yaml
---
- name: This file is dedicated for printing message
  hosts: ubuntu
  tasks:
    - name: Print variables and message
      debug:
        msg:
          - "{{ inventory_hostname }}"
          - "{{ ansible_hostname }}"
          - "Infinix"
```

## gather_facts

If you set `gather_facts` to `no`, the playbook above does not work and gives an error (`ansible_hostname` is a fact).

- `gather_facts` controls whether Ansible collects system information (facts) from the remote node.
- By default `gather_facts` is `true` in playbooks.
- It takes a boolean value: `true`/`false` or `yes`/`no`.

```yaml
- name: gathering information
  hosts: ubuntu
  gather_facts: yes   # yes/no OR true/false
```
