# 13. Checking Processes with Bash and Python Scripts

Services like `nginx` and `sshd` are managed by systemd, so we can use `systemctl` commands to check their status or start them:

```bash
systemctl status nginx
service nginx status
```

Services we define or create ourselves, such as `cloudops_service`, are not managed that way. We can check them with `ps -ef`:

```bash
ps -ef | grep cloudops_service
```

If it shows more than one entry, your service is running; otherwise it is not.

## Bash Version

```bash
#!/bin/bash

# Check nginx process using ps -ef
process_count=$(ps -ef | grep nginx | grep -v grep | wc -l)

if [[ "$process_count" -gt 0 ]]; then
    echo "nginx is running ($process_count instance(s) found)"
else
    echo "nginx is NOT running"
fi
```

```bash
chmod +x check_nginx_ps.sh
./check_nginx_ps.sh
```

## Python Version

```python
import subprocess

def check_process(process_name):
    # Run ps -ef command
    result = subprocess.run(["ps", "-ef"], capture_output=True, text=True)
    
    # Filter lines containing the process name but exclude 'grep' and this python script itself
    processes = [
        line for line in result.stdout.splitlines()
        if process_name in line and "grep" not in line and "python" not in line
    ]
    
    if processes:
        print(f"{process_name} is running ({len(processes)} instance(s) found)")
        for p in processes:
            print(p)
    else:
        print(f"{process_name} is NOT running")

if __name__ == "__main__":
    check_process("nginx")
```

```bash
chmod +x check_nginx_ps.py
./check_nginx_ps.py
```

## Running the Python Script with a Playbook

```yaml
# python_checking_nginx.yml
- name: this yaml file focuses on copying the script file, running it, saving its output and displaying it
  hosts: ubuntu   # my worker machine
  gather_facts: no
  tasks:
  - name: copying the python script file
    copy:
      src: /home/john/ansible/check_nginx_ps.py   # source location of the file
      dest: /home/ubuntu/                         # destination where the file is copied
      mode: 0755                                  # file permissions
      owner: ubuntu
      group: ubuntu
  - name: running the file and saving its output in a variable
    command: "python3 /home/ubuntu/check_nginx_ps.py"
    register: command_output                      # save the script output in a variable with register
  - name: now showing the output of file using debug keyword
    debug:
      var: command_output.stdout_lines            # pass the saved output to debug as a variable
```
