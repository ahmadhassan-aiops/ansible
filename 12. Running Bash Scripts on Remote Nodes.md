# 12. Running Bash Scripts on Remote Nodes

In this topic we write a Bash script and run it on remote nodes through a playbook.

## The Bash Script

A script that checks whether a service is running:

```bash
# vim service_details.sh
#!/bin/bash

service_status=$(systemctl is-active ssh)

if [[ "$service_status" == "active" ]]
then
	echo "ssh service is running"
else
	echo "ssh service is not running"
fi
```

```bash
sudo chmod +x service_details.sh
```

We can run the file locally with `./service_details.sh`, but we need to run it on the worker nodes.

## The Playbook

Copy the script to the worker node, run it, save its output and display it:

```yaml
# vim bash.yml
- name: this yaml file focuses on copying the bash script file, running it, saving its output and displaying it
  hosts: ubuntu
  gather_facts: no
  tasks:
  - name: copying the bash script file
    copy:
      src: /home/john/ansible/service_details.sh   # source location of the file (master machine)
      dest: /home/ubuntu/                          # destination on the worker node
      mode: 0755                                   # file permissions
      owner: ubuntu
      group: ubuntu
  - name: running the file and saving its output in a variable
    command: "bash /home/ubuntu/service_details.sh"
    register: command_output                       # save the script output in a variable with register
  - name: now showing the output of file using debug keyword
    debug:
      var: command_output.stdout_lines             # pass the saved output to debug as a variable
```

If you use `command_output` without `stdout_lines`, you see the complete debug output. To see only the script output, use `stdout_lines`.

Run the playbook:

```bash
ansible-playbook bash.yml
```
