# 28. Ansible Vault

Ansible Vault secures a YAML file and its content with a password. Once secured, you cannot read, edit or run the file without the password. It uses the **AES** algorithm to encrypt data.

## Commands

```bash
# secure a yml file
ansible-vault encrypt sample.yml

# look at the file
cat sample.yml

# run a file secured with vault
ansible-playbook task.yml --ask-vault-pass

# read the file like cat does (after providing the password)
ansible-vault view sample.yml

# decrypt the file so it becomes a normal file again
ansible-vault decrypt sample.yml

# help
ansible-vault --help
```
