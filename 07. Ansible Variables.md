# 07. Ansible Variables

1. **Default variables**: variables that Ansible defines by default.
2. **Inventory variables**: host variables and group variables that you define (covered with playbooks).
3. **Facts and local facts**
4. **Register variables**: variables you register in order to use them (covered with playbooks).

## Example

```bash
ansible all -m debug
ansible all -m debug -a "msg='Ahmad Hassan'"
```

To call any variable in Ansible, use double curly brackets `{{ }}` (Ansible special variables):

Reference: https://docs.ansible.com/ansible/latest/reference_appendices/special_variables.html

```bash
ansible all -m debug -a msg={{inventory_hostname}}
ansible all -m debug -a msg={{hostvars}}
```
