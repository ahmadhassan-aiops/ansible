# 27. Running Specific Tasks with Tags

You can run specific tasks by assigning **tags** to them in the YAML file.

**`never`:** when a task has the `never` tag, it is not executed when you run the playbook normally without mentioning a tag. The task runs only when its tag is mentioned.

## Example

```yaml
# vim tags.yml
---
- name: This is playbook for tags
  hosts: ubuntu
  become: yes
  tasks:
  - name: Installation wget
    apt:
      name: wget
      state: present
    tags:
      - wget_install
  - name: Installation vim
    apt:
      name: vim
      state: present
    tags:
      - vim_install
  - name: Removing wget
    apt:
      name: wget
      state: absent
    tags:
      - wget_remove
  - name: Removing vim
    apt:
      name: vim
      state: absent
    tags:
      - vim_remove
```

Only the task that installs wget is executed:

```bash
ansible-playbook tags.yml --tags wget_install
```

## Multiple Tasks with One Tag, and Nothing by Default

**How do you run multiple tasks with a single tag, and run no tasks when the playbook is run without a tag?**

```yaml
---
- name: This is playbook for tags
  hosts: ubuntu
  become: yes
  gather_facts: false
  tasks:
  - name: Installation wget
    apt:
      name: wget
      state: present
    tags:
      - wget_install
      - imp
      - never
  - name: Installation vim
    apt:
      name: vim
      state: present
    tags:
      - vim_install
      - imp
      - never
  - name: Removing wget
    apt:
      name: wget
      state: absent
    tags:
      - wget_remove
      - never
  - name: Removing vim
    apt:
      name: vim
      state: absent
    tags:
      - vim_remove
      - never
```

The `imp` tag is on the first two tasks, so you can run both of them by mentioning `imp`:

```bash
ansible-playbook tags.yml --tags imp
```

`never` means "do not run in normal mode", so tasks with the `never` tag do not run with this command:

```bash
ansible-playbook tags.yml
```

Run all tasks except `wget_install` (tasks with the `never` tag are also not run):

```bash
ansible-playbook tags.yml --skip-tags wget_install
```
