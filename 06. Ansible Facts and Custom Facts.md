# 06. Ansible Facts and Custom Facts

> *Facts: the concept of retrieving remote information as variables.*

Check the setup of a machine:

```bash
ansible ubuntu -m setup
```

Use filters with the setup module:

```bash
ansible ubuntu -m setup -a "filter='ansible_python_version'"
```

Get information about the master machine:

```bash
ansible localhost -m setup -a "filter='ansible_python_version'"
```

## Creating Custom Facts

Make sure `httpd` is installed on your master machine:

```bash
sudo dnf install httpd -y
```

**Step 1:** Go to `/etc/ansible` on the master machine and create a `facts.d` directory there.

**Step 2:** Create a script in the `facts.d` directory with the `.fact` extension (it can be written in any language):

```bash
vim apache2_status.fact   # for Ubuntu
vim httpd_status.fact     # for RHEL
```

The output of a fact file must be in **JSON** format.

**Fact file for the httpd service on CentOS 9:**

```bash
#!/bin/bash

status=$(systemctl is-active httpd)

if [[ $status == "active" ]]
then
	state="httpd is Running"
else
	state="httpd is not running"
fi
echo "{\"httpd_status:\":\"$state\"}"   # the script output, which must be in JSON format
```

Now run the setup module on localhost and fetch the httpd status with a custom filter:

```bash
ansible localhost -m setup -a "filter=ansible_local"
```

The output shows the httpd status from the setup information.

**Step 3:** Create the `facts.d` directory on both the master and worker machines. Since CentOS 9 is my master, I create `httpd_status.fact` there; since Ubuntu is my worker node, I create an Apache fact file for it.

```console
# cat /etc/ansible/facts.d/apache.fact
#!/bin/bash

status=$(systemctl is-active apache)

if [[ $status == "active" ]]
then
        state="apache is Running"
else
        state="apache is not running"
fi
echo "{\"apache_status:\":\"$state\"}"
```

Create the directory on the worker:

```console
[john@master-ansible ansible]$ ansible ubuntu -m file -a "path=/etc/ansible/facts.d state=directory" -b

    "ansible_facts": {

```

You can create both files on the master and copy them to the node:

```console
[john@master-ansible ansible]$ ansible ubuntu -m copy -a "src=/etc/ansible/facts.d/apache.fact dest=/etc/ansible/facts.d" -b
```

```bash
sudo chmod +x /etc/ansible/facts.d/apache.fact
```

```console
[john@master-ansible ansible]$ ansible ubuntu -m setup -a "filter=ansible_local"
54.166.4.83 | SUCCESS => {

```
