# 17. Installing Packages with when Conditions

This topic installs or removes packages based on the OS flavour.

```yaml
# vim package_install.yml
---
- name: this file is for installation of packages
  hosts: all
  become: yes
  tasks:
  - name: installation of package
    yum:
      name: httpd
      state: present
    when: ansible_os_family in ["RedHat"]

  - name: installation of apache in ubuntu
    apt:
      name: apache2
      state: present
    when: ansible_os_family in ["Debian"]
```

> If the playbook gives an error saying you need root, run it with `-K` so it asks for a password. With `-K`, the password you enter is the root (sudo) password.
