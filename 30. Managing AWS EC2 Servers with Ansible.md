# 30. Managing AWS EC2 Servers with Ansible

## Step 1: Create the EC2 Instance

Create an EC2 instance on AWS, click **Instance actions → Connect → SSH client**, and copy the SSH connection command.

## Step 2: Connect from the Linux Machine

Copy the `.pem` key to your current location on the Linux machine and run the command to open an SSH connection to the AWS EC2 instance.

```bash
# give permission to the key
chmod 400 "ansible_ec2.pem"

# open the ssh connection
ssh -i "ansible_ec2.pem" ec2-user@ec2-34-224-72-91.compute-1.amazonaws.com
```

## Step 3: Ping the EC2 Server

```bash
ping ec2-34-224-72-91.compute-1.amazonaws.com
```

This ping does not work yet, because inbound traffic is not allowed in the instance's security group.

## Step 4: Allow Inbound Traffic

Open the security group of the EC2 instance, go to **Inbound rules** and allow all traffic.

## Step 5: Create a User on the EC2 Instance

Take root control with `sudo -i` and create a user:

```bash
# create the user
useradd aadmin

# add the user to the sudo group
usermod -aG wheel aadmin
```

Now go to your Linux user on the master and enter its `.ssh` directory:

```bash
cd /home/john
cd .ssh

# copy the content of id_rsa.pub
cat id_rsa.pub
```

On the EC2 server, go to the home directory of the `aadmin` user and create a `.ssh` directory if it doesn't exist:

```bash
mkdir /home/aadmin/.ssh
cd .ssh

# create authorized_keys and paste the content of id_rsa.pub from the master user
vim authorized_keys
```

These steps were done as root, which makes root the owner of the `.ssh` directory on the EC2 instance and causes permission problems. Change the ownership and permissions:

```bash
chown -R aadmin:aadmin .ssh
chmod 700 .ssh

# give read/write permission to authorized_keys
cd .ssh
chmod 600 authorized_keys
```

Add the `aadmin` user to the sudoers file on the EC2 instance:

```bash
visudo
```

```
aadmin ALL=(ALL) NOPASSWD:ALL
```

## Step 6: Add the EC2 Server to the Inventory

Make an entry for the EC2 server in the hosts file on your Linux master machine.

## Step 7: Get the AWS Credentials

Get the access key and secret key from your AWS account under **Security credentials**.

```
Access key: <your-aws-access-key-id>
Secret key: <your-aws-secret-access-key>
EC2 instance zone: us-east-1a
```

## Step 8: Build a Dynamic Inventory

When you stop the EC2 instance and start it again, its public IP changes unless you use an Elastic IP.

To deal with this, we retrieve the public IP of the EC2 instances automatically with a Python script. The script runs on the Ansible master machine, not on the EC2 instance. First, give the master machine the AWS credentials (access key, secret key and region):

```bash
export AWS_ACCESS_KEY_ID='<your-aws-access-key-id>'
export AWS_SECRET_ACCESS_KEY='<your-aws-secret-access-key>'
export AWS_DEFAULT_REGION='us-east-1'
```

Install `boto3` and `boto`, which handle session management with AWS:

```bash
python3 -m pip install boto3 boto
```

Save the following code as `ec2_instances.py` on the Ansible master machine:

```python
#!/usr/bin/python3
import boto3
import json

def get_ec2_instances():
    session = boto3.Session()

    ec2 = session.resource('ec2')

    instances = ec2.instances.all()

    inventory = {'_meta': {'hostvars':{}}, 'all':{'children': ['ungrouped']},'ungrouped':{'hosts':[]}}

    for instance in instances:
        if instance.state['Name']=='running':
            inventory['ungrouped']['hosts'].append(instance.public_ip_address)
            inventory['_meta']['hostvars'][instance.public_ip_address] = {
                    'ansible_host': instance.public_ip_address,
                    'ansible_user': 'aadmin',
                    'ansible_ssh_private_key_file': '/home/aadmin/.ssh/id_rsa'

                    }
    return inventory
if __name__ == '__main__':
    inventory=get_ec2_instances()
    print(json.dumps(inventory))
```

## Managing EC2 with Playbooks

Ansible AWS EC2 module: https://docs.ansible.com/ansible/latest/collections/amazon/aws/ec2_instance_module.html

> It is better to encrypt keys with Ansible Vault.

**Launching an EC2 instance:**

```yaml
---
- name: Creation of EC2 instance
  hosts: localhost
  gather_facts: false

  tasks:
    - name: Launching EC2
      ec2:
        instance_type: t2.micro
        image: ami-0dfcb1ef8550277af
        region: us-east-1
        key_name: my-keypair             # replace with your keypair name
        wait: yes
        count: 1
        vpc_subnet_id: subnet-12345678   # replace with your subnet ID
        assign_public_ip: yes
```

**Stopping an instance:**

```yaml
---
- name: Stop EC2 instance
  hosts: localhost
  gather_facts: false

  tasks:
    - name: Stopping EC2 instance
      ec2:
        instance_ids:
          - i-0123456789abcdef0   # replace with your EC2 instance ID
        region: us-east-1
        state: stopped
        wait: yes
```

**Starting an instance:**

```yaml
---
- name: Start EC2 instance
  hosts: localhost
  gather_facts: false

  tasks:
    - name: Starting EC2 instance
      ec2:
        instance_ids:
          - i-0123456789abcdef0   # replace with your EC2 instance ID
        region: us-east-1
        state: running
        wait: yes
```

**Terminating an instance:**

```yaml
---
- name: Terminate EC2 instance
  hosts: localhost
  gather_facts: false

  tasks:
    - name: Terminating EC2 instance
      ec2:
        instance_ids:
          - i-0123456789abcdef0   # replace with your EC2 instance ID
        region: us-east-1
        state: terminate
        wait: yes
```

**Getting details of all EC2 instances in a region:**

```yaml
---
- name: Get details of all EC2 instances in a region
  hosts: localhost
  connection: local
  gather_facts: no

  tasks:
    - name: Get info about all EC2 instances
      amazon.aws.ec2_instance_info:
        region: us-east-1   # change as needed
      register: ec2_info

    - name: Print instance ID and Name tag
      debug:
        msg: "Instance ID: {{ item.instance_id }} | Name: {{ item.tags.Name | default('NoName') }}"
      loop: "{{ ec2_info.instances }}"
```
