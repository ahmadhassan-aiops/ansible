# 19. Data Types in Ansible

Ansible supports these data types:

1. **Scalar types**: int, string, float and boolean
2. **Complex types**: list, dictionary, set, JSON
3. **Special**: Ansible facts and variables (e.g. `{{ inventory_hostname }}`)

## Examples

**String:**
```yaml
name: sara
```

**Boolean:**
```yaml
become: true
```

**List:** `application` is a list whose values are `web` and `db`.
```yaml
application:
- web
- db
```

**Dictionary:** `db_details` is a dictionary with two key-value pairs.
```yaml
db_details:
  host: database
  port: 3306
```

**JSON:**
```yaml
mydata: {"status": "running", "version":"1.2"}
```

**Special:**
```yaml
"hostname": "{{ inventory_hostname }}"
```
