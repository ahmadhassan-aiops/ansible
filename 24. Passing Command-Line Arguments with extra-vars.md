# 24. Passing Command-Line Arguments with extra-vars

This topic shows how to pass arguments to a playbook from the command line.

```yaml
# sudo vim command_arg.yml
---
- name: this yml file is for command line arguments
  hosts: ubuntu
  become: yes
  tasks:
  - name: installing the zip package
    apt:
      name: "{{ package_name }}"
      state: "{{ package_state }}"
```

Run the playbook with either `-e` or `--extra-vars`:

```bash
ansible-playbook command_arg.yml --extra-vars "package_name=zip package_state=present"
```

> If a variable is defined in the playbook and you also pass its value on the command line, the command-line value overrides the value defined in the playbook.
