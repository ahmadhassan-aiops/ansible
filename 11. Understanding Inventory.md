# 11. Understanding Inventory

The inventory file is called `hosts` by default, and its path is defined in `ansible.cfg`. You can have multiple inventory files with different names containing different machines, and define the worker nodes in each one however you like.

Suppose I want to connect to the Ubuntu worker node from the CentOS 9 master node. There are two options:

1. Create an SSH key on CentOS 9 and copy it to Ubuntu for password-free communication.
2. Define the username and password in the inventory file. Whenever Ansible communicates with that node, it uses the username and password from the inventory file.

```ini
[ubuntu]
54.166.4.83 ansible_ssh_user=ubuntu ansible_ssh_pass=********
```

Now you don't need to copy an SSH key from CentOS to Ubuntu.

## Group Variables

What if there are 10 worker nodes? Will you define a user and password for each? In that case you can define variables.

Suppose all 10 worker nodes are on the same network and have the same username and password:

```ini
[all:vars]
ansible_ssh_user=sara
ansible_ssh_pass=*******

[centos1]
192.168.43.63
192.168.43.64
192.168.43.65
```

Now `sara` and `*******` are used to interact with all these machines.

**Case 1: all machines have the same username and password**

```ini
[worker_nodes]
192.168.43.64
192.168.43.65
192.168.43.66
192.168.43.67
192.168.43.68
192.168.43.69
192.168.43.70
192.168.43.71
192.168.43.72
192.168.43.73
192.168.43.74
192.168.43.75

[worker_nodes:vars]
ansible_ssh_user=a
ansible_ssh_pass=ABC
```

**Case 2: each machine has a different username and password**, so we define them individually for every worker node:

```ini
[worker_nodes]

192.168.43.65 ansible_ssh_user=user2 ansible_ssh_pass=password2
192.168.43.66 ansible_ssh_user=user3 ansible_ssh_pass=password3

192.168.43.71 ansible_ssh_user=user8 ansible_ssh_pass=password8
```
